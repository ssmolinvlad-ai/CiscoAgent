# Проверка сценариев 0.2.0

Практические прогоны: 6 ноября 2026; итоговая сборка и автоматические проверки: 7 ноября 2026. Windows 11, Packet Tracer 9.0.0.0810, packet-tracer-mcp 0.11.0. Все сетевые результаты ниже получены через тот же исполнитель, который вызывает интерфейс приложения.

| Сценарий | Подтверждено | Область проверки |
|---|---:|---|
| №2 ARP | 8/8 | Сохранённая сеть лабораторной №1: холодный и тёплый обмен, настоящие поля Ethernet/ARP, все пары ping, очистка кэшей. Отдельно выполнен разрешённый опыт Windows: неверная запись шлюза вызвала потерю ответов, восстановление вернуло связь. |
| №3 Console/VLAN | 9/9 | Вариант 4: настоящий Console/Terminal, Telnet и уровень привилегий 15, 16 устройств, 15 линий, фактические access-порты VLAN и разрешённые/запрещённые направления. |
| №4 STP/EtherChannel | 8/8 | Продолжение сети №3: отказ порта, непрерывный ping, резервный путь, смена корня, LACP. Два потока src-mac прошли через разные физические порты в один момент симуляции; dst-mac — через один порт последовательно. |
| №6 RIP | 8/8 | Искусственный стенд из трёх маршрутизаторов: RIPv2, изменение топологии, метрики, traceroute, отказ и восстановление. |
| №7 OSPF | 10/10 | Тот же искусственный исходный стенд: serial-модули, расширение сети, соседства, разрыв, резервная линия, наблюдаемая смена маршрута при изменении bandwidth, повторный отказ. |

Для №6 и №7 исходного проекта лабораторной №5 пользователя пока нет. Эти результаты подтверждают исполнителя на тестовом стенде, а не выполнение его персональных лабораторных. Результаты и исходные PDF пользователя не публикуются. Схемы вариантов 1–20 проверены автоматически; живой прогон №3 выполнялся для варианта 4.

Автоматические проверки: 83 passed, 1 skipped. Они проверяют в том числе отложенную сходимость OSPF, реальное членство access-портов, отрицательные результаты трафика, восстановление временных отключений и сохранение неподтверждённых требований в отчёте. Имитационные тесты сами по себе не заменяют перечисленные живые прогоны.

Собранный EXE проверяется через `--diagnose-gui`: создание настоящих Qt-виджетов, главного окна и пяти диалогов, сохранение их изображений и проверка параметров. Это не проверка каждого клика в интерактивном рабочем столе. Word-отчёты созданы и структурно проверены; визуальное открытие в Word в эту проверку не входит.

Во время финальной проверки 7 ноября действующий канал Cisco уже был недоступен. Новые сетевые действия не выдаются за выполненные: итоговый разбор VLAN опирается на исходные ответы `show vlan brief` сохранённого живого прогона. Перед следующим запуском должны быть открыты Cisco и MCP Control Center.

Опыт Windows проверен с установленным PowerShell 7 и правами администратора. Приложение не изменяет политику выполнения скриптов. При отсутствии необходимых прав или блокировке скрипта опыт остаётся неподтверждённым; проверки безопасности не отключаются.
